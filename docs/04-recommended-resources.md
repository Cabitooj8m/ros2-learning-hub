# 📚 Recommended Books & Literature

This document presents a structured catalog of essential technical books for learning ROS 2, computer vision, machine learning, and systems engineering. All resources are organized by a difficulty hierarchy to provide a clear reading sequence for students.

---

## 🗺️ Difficulty Hierarchy

```text
Level 1: Core Fundamentals (Basic ROS 2 & Computer Vision)
   └── Level 2: Advanced Systems (Complex ROS 2, C++ & Navigation)
         └── Level 3: Applied AI & Intelligent Robotics (ML, Perception & SLAM)
```

---

## 🟢 Level 1: Core Fundamentals

This level focuses on building fundamental competencies in Python scripting, basic ROS 2 node architecture, and introductory computer vision processing pipelines.

| Title | Author(s) | Primary Domain |
| :--- | :--- | :--- |
| Ultimate Robotics Programming with ROS 2 and Python | Jonathan Cacace | ROS 2 & Python |
| OpenCV Computer Vision with Python | Joseph Howse | Computer Vision |
| A Gentle Introduction to ROS 2 | Jason M. O'Kane | ROS 2 Foundations |

---

## 🟡 Level 2: Advanced Systems & Architecture

This level covers complex multi-node orchestration, Navigation 2 (Nav2), MoveIt 2 manipulation, hardware integration, and high-performance system programming in C++.

| Title | Author(s) | Primary Domain |
| :--- | :--- | :--- |
| Mastering ROS 2 for Robotics Programming (4th Edition) | Lentin Joseph, Jonathan Cacace | Advanced ROS 2 |
| Hands-On ROS 2 for Robotics Programming | Bernardo Ronquillo | ROS 2 & Hardware |
| Effective Modern C++ | Scott Meyers | C++ Systems Programming |

---

## 🔴 Level 3: Applied AI & Intelligent Robotics

This level bridges traditional robotics with modern artificial intelligence, deep learning perception stacks, probabilistic state estimation, and SLAM algorithms.

| Title | Author(s) | Primary Domain |
| :--- | :--- | :--- |
| Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow | Aurélien Géron | Artificial Intelligence & ML |
| Probabilistic Robotics | Sebastian Thrun, Wolfram Burgard, Dieter Fox | Autonomous Mobile Robots & SLAM |
| Deep Learning for Vision Systems | Mohamed Elgendy | Deep Learning & Perception |

---

## 💡 Suggested Reading Sequence

1. Begin with **Level 1** titles to build fundamental skills in basic Python nodes using `rclpy` and image processing workflows with `OpenCV`.
2. Move to **Level 2** titles to learn production-grade ROS 2 architecture, Navigation 2 (Nav2), simulation in Gazebo, and efficient C++ execution (`rclcpp`).
3. Complete your learning path with **Level 3** titles to integrate state-of-the-art perception, deep learning models, and autonomous SLAM algorithms into your robotic applications.
